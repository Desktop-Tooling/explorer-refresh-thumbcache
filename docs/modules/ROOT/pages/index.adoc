Explorer Refresh Thumbcache adds a context-menu command that clears Windows thumbnail and icon cache databases, removes a selected folder's legacy `thumbs.db` when present, and restarts Explorer so previews regenerate on the next browse.

Windows does not provide a supported way to invalidate one folder inside the central thumbnail cache. The tool therefore clears the central cache even when it was invoked for a selected folder.

== Install

The repository provides a per-user PowerShell installer and an Inno Setup package. Build the D application with LDC for the release `-nogc` configuration, then run `installer/Install.ps1` or compile and run the Inno Setup installer.

The command requests a top position in the Windows 11 context menu where supported; otherwise it remains available under "Show more options."
